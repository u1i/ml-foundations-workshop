# Machine learning foundations: workshop notebooks

Exercises for a two-day workshop on practical machine learning and data science. All data is synthetic and generated by `scripts/make_data.py`.

Each notebook is a guided exercise. Every step is one cell: click the play button on its left and read what appears below it. Some steps have a field on the right of the cell (a choice, a slider or a text box): set it and click play again. No coding is needed. The *Stretch* cells at the end of each notebook are optional and for those who like to code.

To keep your choices, use *File, Save a copy in Drive* after opening a notebook.
